# 🎮 Video Game Sales Analysis Dashboard

An end-to-end data analytics project focused on uncovering insights from global video game sales data using Python and Tableau/Power BI.  
This project analyzes market trends, platform performance, genre popularity, publisher success, and regional sales distribution.

---

# 📌 Project Overview

The gaming industry has generated billions in revenue worldwide.  
This project explores historical video game sales data to identify:

- Best-selling games
- Top-performing platforms
- Popular genres
- Leading publishers
- Regional market trends
- Yearly sales growth patterns

The project combines **data cleaning, exploratory data analysis (EDA), visualization, and dashboard development** to transform raw data into meaningful business insights.

---

# 🚀 Project Objectives

✔ Analyze global video game sales trends  
✔ Identify top-selling games and platforms  
✔ Compare sales performance across regions  
✔ Discover the most popular genres  
✔ Build an interactive dashboard for business insights  
✔ Practice real-world data analytics workflow

# 📂 Dataset Information

The dataset contains video game sales records across multiple regions.

### Dataset Features

| Column | Description |
|---|---|
| Name | Video Game Name |
| Platform | Gaming Platform |
| Year | Release Year |
| Genre | Game Category |
| Publisher | Publishing Company |
| NA_Sales | North America Sales |
| EU_Sales | Europe Sales |
| JP_Sales | Japan Sales |
| Other_Sales | Other Region Sales |

# 📈 Key Business Insights

📌 Action games generated the highest global sales  
📌 Nintendo dominated the gaming market for multiple years  
📌 Wii and PS2 became top-selling platforms  
📌 North America contributed the largest share of sales  
📌 Global video game sales peaked around 2008–2009  
📌 Japan showed strong preference for Role-Playing games
